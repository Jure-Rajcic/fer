# Computer Animation 📂

### 📖 Course Overview
In the Computer Animation course, fundamental and advanced concepts and techniques for representing 3D objects and realizing their animated presentation are explored, forming the necessary foundation for computer graphics engineering. Understanding essential graphics principles—from position and orientation interpolation to hierarchical, complex kinematic and dynamic structures—is key to mastering computer animation. The syllabus covers advanced topics including bump mapping, parallax effects, real-time collision detection, and physically-based animation procedures.

### 🔬 Lab Experiments (🇭🇷)
Hands-on laboratory exercises implementing 2D/3D graphics, motion interpolation, and particle physics:
- **Exercise 0**: Introduction to OpenGL & GLUT on macOS (Window initialization, viewport/projection transformations, camera controls, and idle-loop rotation rendering)
- **Exercise 1**: B-Spline Path Tracking & Orientation Control (3D B-spline curve interpolation, tangent vector evaluation, axis-angle rotation, and Frenet-Serret frame alignment)
- **Exercise 2**: Interactive Particle Systems (Pyglet-based real-time 2D particle simulation with gravity dynamics, life cycles, and visual death effects)
- **Exercise 3**: Web-based Graphics & Animation Project (Nx monorepo with Angular application architecture and deployment setup)
