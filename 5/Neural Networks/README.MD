# Neural Networks 📂

### 📖 Course Overview
This course provides comprehensive knowledge in the theory and practical applications of artificial neural networks. The syllabus explores biological and artificial neural networks, artificial neuron models, activation functions, and network topologies. Core topics include the Perceptron, associative memory and linear associators, multilayer networks, the delta learning rule and error backpropagation, Support Vector Machines (SVM), radial basis function networks (RBFN), recurrent networks (Hopfield networks, energy functions, and Boltzmann machines), simulated annealing, k-means clustering, Kohonen self-organizing maps (SOM), and deep learning architectures with simulation software suites. Applications focus on pattern recognition, signal analysis, and computer vision.
