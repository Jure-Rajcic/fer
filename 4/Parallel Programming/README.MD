# Parallel Programming 📂

### 📖 Course Overview
This course highlights the need to develop algorithms capable of harnessing the expanding computational power offered by large clusters of computers. Students explore fundamental principles of parallel algorithm design, corresponding parallel computer architectures, and parallel programming paradigms. The syllabus covers the practical application of parallel development technologies across diverse computing environments, with special attention given to designing modular parallel software architectures capable of executing within complex distributed and multi-core systems.

### 🔬 Lab Experiments (🇭🇷)
Distributed and GPU-accelerated parallel computing implementations using MPI (`mpi4py`) and OpenCL (`pyopencl`, C++ OpenCL):
- **Lab 1**: Distributed Synchronization & Dining Philosophers Problem with MPI (`mpi4py`)
- **Lab 2**: Distributed Game Tree Search & Minimax Alpha-Beta Pruning for Connect Four with MPI (`mpi4py`)
- **Lab 3**: GPU Computing with OpenCL:
  - Vector reduction & kernel execution parameter optimization (`pyopencl`)
  - 2D grid stencil computation / Jacobi iteration simulation (C++ OpenCL kernel vs. sequential baseline)
