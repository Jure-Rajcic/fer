# Digital Image Processing and Analysis 📂

### 📖 Course Overview
Fundamentals of the human visual system. Two-dimensional (2D) sequences and linear 2D systems. 2D convolution, sampling, and quantization. Image transformations and enhancement in the spatial domain (histogram operations, histogram equalization, histogram modeling, homomorphic filtering, and median filtering). Frequency-domain image enhancement. Image restoration techniques: inverse and pseudo-inverse filtering, and Wiener filtering. Geometric image transformations. Color image representation and processing. Image feature extraction and Principal Component Analysis (PCA). Edge detection, gradient operators, and compass operators. Object boundary detection and image segmentation (Hough transform, clustering methods, texture segmentation, and optical flow). Real-world applications across biomedicine, communications, robotics, and industrial quality control.
