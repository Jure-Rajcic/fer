# Seminar 1 📂

### 🎓 Application of Machine Learning in SVG Illustration Generation
*(Primjena strojnog učenja u generiranju ilustracija u SVG formatu)*

**Author:** Jure Rajčić  

---

### 📖 Overview
This seminar research focuses on exploring and designing machine learning methods for generating illustrations in scalable vector graphic (SVG) format from natural text prompts with a predefined, consistent visual style.

Key phases and research objectives include:
- **Data Collection**: Scraping and curating vector illustrations along with textual descriptions from open platforms (e.g., `undraw.co/illustrations`), preserving both SVG structure and descriptive metadata.
- **Generative Model Fine-Tuning**: Fine-tuning open-source text-to-image diffusion models (such as Stable Diffusion) to specialize in clean, flat, stylized illustration generation while preserving distinctive silhouettes and color simplicity.
- **Image Segmentation & SVG Vectorization**: Applying computer vision segmentation algorithms to raster diffusion outputs to enable clean path vectorization and conversion into native SVG assets.
- **Experimental Evaluation & Architecture Comparison**: Comparing multiple model configurations, optimizations, and vectorization pipelines to identify the most effective architecture.
