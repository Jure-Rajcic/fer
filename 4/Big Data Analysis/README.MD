# Big Data Analysis 📂

### 📖 Course Overview
Analysis of massive datasets (AVSP) addresses algorithmic paradigms and scalable systems required to extract knowledge from very large quantities of data. The course covers finding near-duplicate items, locality-sensitive hashing (LSH), mining frequent itemsets and association rules, web advertising algorithms, clustering at scale, graph link analysis (PageRank), community detection in social graphs, streaming data algorithms, collaborative filtering recommendation systems, and dimensionality reduction techniques.

### 🔬 Lab Experiments (🇭🇷)
Hands-on implementations in Python tackling large-scale algorithmic and data mining challenges:
- **Lab 1**: Near-Duplicate Detection using **SimHash** and Locality-Sensitive Hashing (**SimHashBuckets**)
- **Lab 2**: Collaborative Filtering (**CF.py**) & Recommendation Algorithms (Item-Item & User-User collaborative filtering)
- **Lab 3**: Community Detection in Social Network Graphs via the **Girvan-Newman Algorithm** (`GNAlgorithm.py`)
- **Lab 4**: Scalable Data Stream Mining and Itemset Counting
- **Lab 5**: Graph Link Analysis:
  - **NodeRank** (Random Walk & PageRank variant implementation)
  - **ClosestBlackNode** (Shortest path exploration in bipartite/colored graphs)
- **Lab 6**: Dimensionality Reduction & Matrix Factorization
