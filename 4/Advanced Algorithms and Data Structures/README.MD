# Advanced Algorithms and Data Structures 📂

### 📖 Course Overview
Algorithm contracts and cost models. Balanced search trees, B-trees, and LSM-trees. Text data structures (suffix arrays, FM-index). Geometric algorithms and nearest neighbor search (HNSW). Graph structure (strongly connected components). Shortest paths (A*), dynamic programming, and greedy algorithms. Network flow, bipartite matching, and the assignment problem. Linear programming (simplex) and duality. Approximation algorithms. Data compression (Huffman, Lempel-Ziv, BPE) and succinct data structures. Randomization and sketches (HyperLogLog). Spectral algorithms (PageRank). Compositional algorithm design.
